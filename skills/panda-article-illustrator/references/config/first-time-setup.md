# 首次配置流程

## 概述

当 EXTEND.md 文件不存在时，必须先完成首次配置。此步骤为 **阻塞步骤** — 在完成之前不得进行任何其他操作。

---

## 配置流程

使用 **AskUserQuestion** 工具，在**一次调用**中包含所有问题。

### 问题列表

**Q1: 默认风格**（单选）

```
请选择默认的配图风格：
- 矢量插画（推荐，适合大多数场景）
- 极简手绘（notion 风格，简洁知性）
- 蓝图（技术感，适合系统/架构）
- 温暖（友好亲切，适合叙事/教育）
- 水彩（艺术感，适合生活/创意）
- 丝网印刷（海报感，适合观点/评论）
- 自动（根据内容自动选择）
```

**Q2: 默认平台**（单选）

```
请选择主要发布平台：
- 小红书（默认 3:4 竖屏）
- 微信公众号（默认 16:9 横屏）
- 微博（默认 16:9 横屏）
- 通用（默认 16:9，不针对特定平台）
```

**Q3: 输出目录**（单选）

```
配图文件保存在哪里？
- imgs-subdir（推荐）— 保存到 {文章目录}/imgs/
- same-dir — 保存到文章同级目录
- illustrations-subdir — 保存到 {文章目录}/illustrations/
- independent — 保存到独立的 illustrations/{主题}/ 目录
```

**Q4: 角色配置**（单选）

```
是否配置卡通角色融合？
- 暂不配置（推荐，以后可以随时添加）
- 配置角色
```

如果用户选择"配置角色"，追加一个后续问题（新的 AskUserQuestion 调用）：

**Q4a: 角色图片路径**（文本输入）

```
请提供卡通角色图片的路径（支持绝对路径或相对路径）：
例如：~/.panda-skills/characters/my-avatar.png
```

**Q4b: 角色名称**（文本输入）

```
给角色起个名字：
例如：小熊猫
```

---

## 生成 EXTEND.md

根据用户的回答，生成 EXTEND.md 文件。

### 无角色的模板

```markdown
## 设置
默认风格: [用户选择]
默认平台: [用户选择]
默认输出目录: [用户选择]
水印: 关闭
语言: auto
```

### 有角色的模板

```markdown
## 设置
默认风格: [用户选择]
默认平台: [用户选择]
默认输出目录: [用户选择]
水印: 关闭
语言: auto

## 角色
角色图片: [用户提供的路径]
角色名称: [用户提供的名称]
角色风格: 可爱卡通
默认融合模式: 讲解者
```

---

## 保存位置

询问用户保存位置：

```
EXTEND.md 保存到哪里？
- 当前项目（推荐，仅在此项目生效）→ .panda-skills/panda-article-illustrator/EXTEND.md
- 用户目录（全局生效）→ ~/.panda-skills/panda-article-illustrator/EXTEND.md
```

保存后显示确认：

```
偏好设置已保存！

位置：[保存路径]
风格：[style] | 平台：[platform]
输出目录：[output_dir]
角色：[名称] 或 "未配置"
```

---

## 后续修改

用户可以随时手动编辑 EXTEND.md 文件来修改配置。

添加角色：在 EXTEND.md 中添加"## 角色"区块即可。
修改风格：直接编辑对应的配置值。
删除角色：移除"## 角色"区块即可恢复为无角色模式。
