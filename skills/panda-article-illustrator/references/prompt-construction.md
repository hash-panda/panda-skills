# 提示词构建指南

## 提示词文件格式

每个提示词文件使用 YAML 前置元数据 + 正文内容：

```yaml
---
illustration_id: 01
type: infographic
style: blueprint
character_role: narrator
references:                    # ⚠️ 仅当文件确实存在于 references/ 目录时才填写
  - ref_id: 01
    filename: 01-ref-diagram.png
    usage: direct              # direct | style | palette
---

[下方为类型化模板内容...]
```

**⚠️ 关键 - 何时包含 `references` 字段**：

| 情况 | 操作 |
|------|------|
| 参考文件已保存到 `references/` | 在前置元数据中包含 ✓ |
| 仅口头提取了风格（无文件） | **不要**包含在前置元数据中，改为追加到正文 |
| 前置元数据中有路径但文件不存在 | 错误 - 移除 references 字段 |

**参考图用途类型**（仅当文件存在时）：

| 用途 | 描述 | 生成时的操作 |
|------|------|-------------|
| `direct` | 主要视觉参考 | 传递给 `--ref` 参数 |
| `style` | 仅提取风格特征 | 在提示词正文中描述风格 |
| `palette` | 提取配色方案 | 在提示词中包含颜色值 |

---

## 默认构图要求

**适用于所有提示词**：

| 要求 | 描述 |
|------|------|
| **简洁构图** | 布局简单，避免视觉杂乱 |
| **留白充分** | 元素周围保持足够的呼吸空间 |
| **背景简单** | 纯色或微妙渐变，避免复杂纹理 |
| **合理布局** | 主视觉元素居中或按内容需求定位 |
| **匹配主题** | 图形元素与内容主题对齐 |
| **突出核心** | 留白引导注意力到关键信息 |

**追加到所有提示词末尾**：
> 简洁构图，充分留白。背景简单或无背景。主要元素居中或按内容需求定位。

---

## 人物渲染（无角色时）

当画面中需要出现人物但**未启用角色融合**时：

| 规则 | 描述 |
|------|------|
| **风格** | 简化的卡通剪影或符号化表达 |
| **避免** | 写实人物肖像、精细面部特征 |
| **多样性** | 出现多人时使用不同体型 |
| **情绪** | 通过姿态和简单手势表达 |

**追加到含人物的提示词**：
> 人物形象：简化风格化的剪影或符号化表达，不使用写实风格。

---

## 角色区块（有角色时）

当启用角色融合时，在提示词的"风格"区块之前注入"角色"区块。

### 注入位置

```
[标题] - [类型描述]

[类型化结构内容：区域/标签/步骤等]

角色：                              ← 在风格区块之前插入
- [角色描述]
- 融合模式：[模式]
- 位置：[画面位置]
- 动作：[具体动作]
- 表情：[表情描述]
- 占比：[画面占比百分比]
- 融合细节：[与画面融合的细节描述]

风格：[风格特征]
比例：[宽高比]
```

### 融合模式对应的提示词模板

**讲解者模板**：
```
角色：
- [角色名称]，一个[角色风格]的卡通角色（与参考图保持一致）
- 融合模式：讲解者 — [位置描述]
- 动作：[指向/展示/引导] [具体指向的内容]
- 表情：[根据内容语义选择]
- 占比：约占画面高度的 15-25%
- 融合细节：角色与内容区域有清晰的空间分离，通过手势建立视觉联系
```

**参与者模板**：
```
角色：
- [角色名称]，一个[角色风格]的卡通角色（与参考图保持一致）
- 融合模式：参与者 — 在场景中[做什么]
- 动作：[使用/操作/观察/行走] [与场景的互动描述]
- 表情：[根据内容语义选择]
- 占比：约占画面高度的 25-40%
- 融合细节：角色自然融入场景环境，与道具和背景元素互动，使用相同光照和透视
```

**点缀模板**：
```
角色：
- [角色名称]，一个[角色风格]的卡通角色（与参考图保持一致）
- 融合模式：点缀 — [位置，如"左下角"]
- 动作：[简单表情动作，如"竖起大拇指"]
- 表情：[根据内容语义选择]
- 占比：约占画面高度的 10-15%
- 融合细节：角色半身出现在角落，可配小装饰（星星、对话气泡），不遮挡核心内容
```

### 角色风格适配

角色描述需要随配图风格调整：

| 配图风格 | 角色风格调整 |
|----------|-------------|
| 矢量插画（vector-illustration） | 扁平矢量风格，粗黑轮廓线，纯色填充 |
| 极简（notion） | 简笔画线条，手绘感，单色或双色 |
| 蓝图（blueprint） | 线框图风格，白色轮廓在深蓝背景上 |
| 温暖（warm） | 柔和色调，圆润线条，温馨感 |
| 水彩（watercolor） | 水彩渲染，柔和边缘，自然质感 |
| 丝网印刷（screen-print） | 剪影风格，有限色彩，半色调纹理 |
| 粉笔（chalkboard） | 粉笔笔触，黑板效果 |

## 画面中的文字

| 要素 | 规则 |
|------|------|
| **字号** | 大号、醒目、一眼可读 |
| **字体** | 偏好手写风格增加亲切感 |
| **内容** | 简洁的关键词和核心概念 |
| **语言** | 与文章语言一致 |

**追加到含文字的提示词**：
> 文字应该大号醒目，使用手写风格字体。保持精简，聚焦关键词。

---

## 构建原则

好的提示词必须包含：

1. **先描述布局结构**：构图、区域划分、视觉流向
2. **使用具体数据/标签**：文章中的真实数字、术语、指标
3. **视觉关系**：元素之间如何连接
4. **语义化配色**：基于含义的颜色选择（红色=警告，绿色=高效）
5. **风格特征**：线条处理、纹理、情绪
6. **宽高比**：最后标注比例和复杂度

## 类型化模板

### 信息图（infographic）

```
[标题] - 数据可视化

布局：[网格/放射/层级]

区域：
- 区域 1：[数据点，含具体数值]
- 区域 2：[对比内容，含指标]
- 区域 3：[总结/结论]

标签：[文章中的具体数字、百分比、术语]
颜色：[语义化配色映射]

角色：                           ← 仅在有角色时包含
- [角色提示词]

风格：[风格特征]
比例：3:4
```

**信息图 + 矢量插画**：
```
扁平矢量插画信息图。所有元素使用清晰的黑色轮廓线。
颜色：奶油色背景(#F5F0E6)、珊瑚红(#E07A5F)、薄荷绿(#81B29A)、芥末黄(#F2CC8F)
元素：几何简化图标，无渐变，趣味装饰元素（圆点、星星）
```

### 场景图（scene）

```
[标题] - 氛围场景

焦点：[主要对象]
氛围：[光线、情绪、环境]
情绪：[要传达的情感]
色温：[暖色调/冷色调/中性]

角色：                           ← 仅在有角色时包含
- [角色提示词]

风格：[风格特征]
比例：3:4
```

### 流程图（flowchart）

```
[标题] - 流程展示

布局：[从左到右/从上到下/环形]

步骤：
1. [步骤名称] - [简要描述]
2. [步骤名称] - [简要描述]
...

连接：[箭头类型、决策节点]

角色：                           ← 仅在有角色时包含
- [角色提示词]

风格：[风格特征]
比例：3:4
```

### 对比图（comparison）

```

- [要点 2]

右侧 - [选项 B]：
- [要点 1]

- [角色提示词]

节点：
- [概念 1] - [角色]

角色：                           ← 仅在有角色时包含
- [角色提示词]

```

```
[标题] - 时间视图

- [日期/阶段 1]：[里程碑]
- [日期/阶段 2]：[里程碑]

角色：                           ← 仅在有角色时包含
- [角色提示词]

```

### 丝网印刷风格覆盖

当 `style: screen-print` 时，替换标准风格指令为：

```
丝网印刷/海报艺术风格。使用扁平色块，不使用渐变。
颜色：最多 2-5 种颜色。[从风格色板或双色调中选择]
纹理：半色调网点图案，轻微的色层错位，纸张纹理
构图：大胆的剪影，几何构图，负空间作为叙事元素
人物：仅使用剪影，无精细面部，模板裁切边缘
文字：粗体窄字距无衬线字体，融入构图（非覆盖）
```

---

## 避免事项

- 模糊描述（"一张好看的图"）
- 字面化的隐喻图解
- 缺少具体标签/注释
- 通用装饰元素

## 水印

如果偏好设置中启用了水印，追加：

```
在[位置]添加一个不显眼的水印"[内容]"。水印应可辨认但不影响主要内容。
```
