# 社交平台预设

## 平台参数总览

| 平台 | 代码 | 默认比例 | 备选比例 | 信息密度 | 文字大小 |
|------|------|----------|----------|----------|----------|
| 小红书 | `xhs` | 3:4 | 1:1, 4:3 | 中高 | 大号醒目 |
| 微信公众号 | `wechat` | 16:9 | 1:1, 4:3 | 中等 | 标准 |
| 微博 | `weibo` | 16:9 | 1:1, 9:16 | 中等 | 标准 |
| 通用 | `general` | 16:9 | 3:4, 1:1 | 标准 | 标准 |

---

## 小红书（xhs）

小红书以竖屏图文为主，用户在信息流中快速滑动，配图需要在第一眼吸引注意力。

| 属性 | 设置 |
|------|------|
| **推荐比例** | 3:4（竖屏，信息流最佳展示） |
| **备选比例** | 1:1（正方形，适合多图拼接）、4:3（横屏，适合教程） |
| **信息密度** | 中高 — 每张图包含 3-5 个信息点 |
| **文字处理** | 大号醒目，手写感字体，关键词突出 |
| **配色** | 明亮活泼，高饱和度，对比强烈 |
| **角色融合** | 角色可以稍大（占比上调 5%），表情更夸张 |

### 排版建议

- 标题区域占画面上方 20-25%
- 核心内容区域居中 50-60%
- 底部留白或放角色 15-25%
- 边距不少于画面宽度的 5%

---

## 微信公众号（wechat）

微信公众号以横屏长图文为主，配图嵌入在文章段落之间，需要与文字排版协调。

| 属性 | 设置 |
|------|------|
| **推荐比例** | 16:9（横屏，与文章排版协调） |
| **备选比例** | 1:1（正方形，居中展示）、4:3（偏横屏） |
| **信息密度** | 中等 — 每张图包含 2-4 个信息点 |
| **文字处理** | 标准大小，清晰可读，与文章字体风格协调 |
| **配色** | 偏素雅，与文章白色背景和谐 |
| **角色融合** | 标准占比，融入感要强，避免喧宾夺主 |

### 排版建议

- 横向布局，信息从左到右流动
- 留白充分，与文章的白色背景融合
- 避免过于花哨的装饰
- 配图宽度通常为文章内容宽度的 100%

---

## 微博（weibo）

微博以横屏为主，但也支持竖屏九宫格。配图在时间线中需要快速传达信息。

| 属性 | 设置 |
|------|------|
| **推荐比例** | 16:9（横屏，时间线展示最佳） |
| **备选比例** | 1:1（九宫格）、9:16（竖屏长图） |
| **信息密度** | 中等 — 信息点要精简 |
| **文字处理** | 标准到偏大，快速扫描即可理解 |
| **配色** | 较鲜明，在信息流中有辨识度 |
| **角色融合** | 标准占比 |

### 排版建议

- 信息精简，一图一个核心观点
- 关键数字/结论放大突出
- 适合使用对比图和信息图类型

---

## 通用（general）

不针对特定平台，适用于博客文章、技术文档等场景。

| 属性 | 设置 |
|------|------|
| **推荐比例** | 16:9（横屏标准） |
| **备选比例** | 3:4（竖屏）、1:1（正方形） |
| **信息密度** | 标准 — 根据内容复杂度自适应 |
| **文字处理** | 标准，注重可读性 |
| **配色** | 中性专业，适应各种背景 |
| **角色融合** | 标准占比 |

---

## 使用方式

### 命令行指定

```bash
# 为小红书平台优化
/panda-article-illustrator article.md --platform xhs

# 为微信公众号优化
/panda-article-illustrator article.md --platform wechat

# 组合使用
/panda-article-illustrator article.md --platform xhs --preset knowledge-base --role narrator
```

### EXTEND.md 默认配置

```markdown
## 设置
默认平台: xhs
```

设置后无需每次指定 `--platform`。命令行参数优先于 EXTEND.md 配置。
