# 角色风格 × 配图风格 兼容性

## 概述

当角色融入配图时，角色的绘制风格需要与配图的整体风格协调。本文档描述了不同配图风格下角色应如何调整视觉表现。

## 风格适配规则

### 矢量插画（vector-illustration）

```
角色调整：使用扁平矢量风格渲染角色
- 粗黑轮廓线
- 纯色填充，无渐变
- 简化细节，保留核心特征
- 配色与画面整体色板统一（珊瑚红/薄荷绿/芥末黄等）
```

### 极简手绘（notion）

```
角色调整：简化为线条画风格
- 单色或双色线条
- 手绘感笔触
- 极简面部特征（点眼睛、简单嘴巴）
- 去除所有装饰性细节
```

### 蓝图（blueprint）

```
角色调整：线框图风格
- 白色或浅蓝轮廓线
- 深蓝背景上的线条角色
- 技术图纸感
- 角色可带标注线（类似工程标注）
```

### 温暖（warm）

```
角色调整：保持原有卡通风格，增加温暖感
- 柔和色调
- 圆润线条
- 金色/暖色光照
- 自然、亲切的表达
```

### 水彩（watercolor）

```
角色调整：水彩渲染效果
- 柔和边缘，颜色微微晕染
- 保留角色基本轮廓
- 自然质感
- 与背景水彩风格统一
```

### 丝网印刷（screen-print）

```
角色调整：剪影化处理
- 角色简化为剪影
- 仅使用画面中的有限色彩
- 半色调纹理覆盖
- 模板裁切边缘感
注意：丝网印刷风格下角色极度简化，建议使用"点缀"模式或"无角色"
```

### 粉笔画（chalkboard）

```
角色调整：粉笔笔触
- 白色/彩色粉笔线条
- 黑板背景
- 手绘粗糙质感
- 保留角色识别度的前提下简化
```

## 自动适配逻辑

当用户的角色风格与配图风格不兼容时（矩阵中标记为 ✗）：

1. **优先调整角色渲染**：在提示词中描述将角色以配图风格重新渲染
2. **降级融合模式**：从"参与者"降级为"点缀"，减少角色占比
3. **提示用户**：告知兼容性问题，建议调整风格选择或接受降级
