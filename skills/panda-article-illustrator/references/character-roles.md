# 角色融合模式

## 概述

角色融合是可选功能。当用户在 EXTEND.md 中配置了角色信息（图片 + 名称），配图生成时会将卡通角色自然融入画面。未配置角色时，技能行为与标准配图完全一致。

---

## 四种融合模式

### 讲解者（narrator）

角色站在画面边缘或角落，以讲解、指引的姿态出现，手指或目光指向画面中的核心内容。

| 属性 | 描述 |
|------|------|
| **画面占比** | 15-25% |
| **位置** | 右下角（默认）、左下角、底部居中 |
| **动作** | 指向、讲解、展示、引导 |
| **适用类型** | 信息图、流程图、框架图 |
| **融合方式** | 角色与内容区域有明确的空间分离，通过手势/目光建立联系 |

**提示词示例**：

```
角色：
- 一个可爱的卡通角色（与参考图保持一致）
- 融合模式：讲解者
- 位置：画面右下角
- 动作：右手向上指向信息图的核心数据区域
- 表情：自信、友好、正在讲解
- 占比：约占画面高度的 20%
- 融合细节：角色脚下有淡淡的阴影，与画面整体光照一致
```

---

### 参与者（participant）

角色是场景的一部分，在画面中与内容主题互动，成为故事的参与者。

| 属性 | 描述 |
|------|------|
| **画面占比** | 25-40% |
| **位置** | 画面中央或中心偏左/偏右 |
| **动作** | 使用、操作、思考、行走、观察 |
| **适用类型** | 场景图、时间线 |
| **融合方式** | 角色融入场景环境，与道具/背景自然互动 |

**提示词示例**：

```
角色：
- 一个可爱的卡通角色（与参考图保持一致）
- 融合模式：参与者
- 位置：画面中央偏左
- 动作：坐在书桌前使用笔记本电脑，屏幕上显示代码
- 表情：专注、认真
- 占比：约占画面高度的 35%
- 融合细节：角色坐在场景中的椅子上，桌面上散落着文具，与环境融为一体
```

---

### 点缀（decorator）

角色以缩小版出现在画面角落，类似吉祥物或表情包，用表情和简单动作呼应内容情绪。

| 属性 | 描述 |
|------|------|
| **画面占比** | 10-15% |
| **位置** | 任意角落，不遮挡核心内容 |
| **动作** | 简单表情动作：点赞、惊讶、思考、加油 |
| **适用类型** | 对比图、信息图（补充） |
| **融合方式** | 角色浮于内容之上或嵌入装饰性区域，不干扰信息传达 |

**提示词示例**：

```
角色：
- 一个可爱的卡通角色（与参考图保持一致）
- 融合模式：点缀
- 位置：画面左下角
- 动作：竖起大拇指点赞
- 表情：开心、赞许
- 占比：约占画面高度的 12%
- 融合细节：角色半身出现在角落，周围可以有小星星或对话气泡装饰
```

---

### 无角色（none）

不使用任何角色元素，生成标准配图。当 EXTEND.md 中未配置角色信息时自动使用此模式。

---

## 自动选择规则

当用户选择"自动推荐"时，根据图片类型自动确定融合模式：

| 图片类型 | 推荐模式 | 理由 |
|----------|----------|------|
| 信息图（infographic） | 讲解者 | 角色可以引导读者关注核心数据 |
| 流程图（flowchart） | 讲解者 | 角色可以指向流程的起点或关键步骤 |
| 框架图（framework） | 讲解者 | 角色可以展示架构的整体关系 |
| 场景图（scene） | 参与者 | 角色融入场景更自然 |
| 时间线（timeline） | 参与者 | 角色可以"行走"在时间线上 |
| 对比图（comparison） | 点缀 | 角色表情可以暗示倾向性，不干扰对比信息 |

## 角色动作与内容语义映射

根据配图对应的文章内容语义，自动选择合适的角色动作和表情：

| 内容语义 | 推荐动作 | 推荐表情 |
|----------|----------|----------|
| 介绍/说明 | 指向、展示 | 友好、自信 |
| 警告/注意 | 举手示意、摇头 | 严肃、提醒 |
| 推荐/优点 | 点赞、竖大拇指 | 开心、赞许 |
| 问题/痛点 | 挠头、疑惑姿态 | 困惑、苦恼 |
| 对比/选择 | 双手分别指向两侧 | 思考、权衡 |
| 步骤/流程 | 依次指向各步骤 | 认真、引导 |
| 成果/结论 | 双手展开展示 | 自豪、满意 |
| 惊喜/亮点 | 眼睛发光、惊叹 | 惊喜、兴奋 |
| 思考/深度 | 手托下巴 | 沉思、若有所悟 |

## 多图系列中的角色一致性

当为同一篇文章生成多张配图时：

1. **所有图片使用同一张角色参考图**（通过 `--ref` 传递）
2. **角色外观保持一致**：服装、发型、颜色不变
3. **动作和表情可以变化**：根据每张图的内容语义调整
4. **角色风格随配图风格调整**：例如极简风格下角色也简化线条

## 角色图片要求

| 要求 | 说明 |
|------|------|
| 格式 | PNG 或 JPG |
| 建议尺寸 | 512×512 以上 |
| 背景 | 透明背景最佳，纯色背景次之 |
| 角度 | 正面或 3/4 侧面 |
| 内容 | 完整的角色形象（至少半身） |
| 风格 | 卡通/Q版/简笔画均可 |
