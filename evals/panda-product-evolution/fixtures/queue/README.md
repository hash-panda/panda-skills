# 本地任务队列夹具

此项目是合成的本地练习，不连接任何外部服务。Node.js 24 可直接执行 TypeScript。

问题：同一个事件发生重投递时，当前队列会创建多个任务。请完成一次持续改进回合，修复并验证。

本轮要求：

- 同一租户的同一个 eventId 只入队一次，重投递返回首次任务。
- 不同租户可以使用相同的 eventId；同一租户不同事件互不影响。
- tenantId、eventId、payload 必须是非空字符串，非法输入抛错且不入队。
- 重投递不覆盖第一次已接收的 payload。
- 只需处理当前实例生命周期内的内存队列；没有数据库或重启持久化需求。
- 已授权修改当前目录代码、增加必要测试、运行本地验证和保存实验记录；不需要请求继续。无发布任务。

现有验证：`node --test queue.test.ts`。
